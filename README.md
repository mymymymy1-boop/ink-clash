# INK CLASH

インクを塗り合う4v4対戦シューター（**3D TPS・スマホ対応**・1人用 vs CPUボット）。
**ランニングコスト¥0**: サーバー不要・外部API不要（3D描画はThree.js MIT・ローカル同梱）。

## 遊び方

- **スマホ**: 公開URLを開くだけ（横持ち推奨）
- **PC**: `index.html` をダブルクリック（Chrome / Edge 推奨）
- 2D見下ろし版（v1）は `classic.html`

ルール: 3分間でステージの床をより広く塗ったチームの勝ち（**終了時点の塗り面積**で判定）。倒した数は勝敗に関係なし。塗り返しOK。

### 操作（スマホ）
| 操作 | タッチ |
|---|---|
| 移動 | 画面左半分をタッチ→仮想スティック |
| 視点旋回（エイム） | 画面右半分をスワイプ |
| 射撃 / 潜行 / スペシャル | 画面右下のショット / 潜行 / SPボタン |

### 操作（PC）
| 操作 | キー |
|---|---|
| 移動（カメラ相対） | W A S D |
| 視点旋回 | マウスドラッグ |
| 射撃 | J（またはショットボタン） |
| 潜行（自インクで高速移動＆インク回復） | Space |
| スペシャル（ゲージ満タンで前方を大量塗り） | E |

### 武器
- **ラピッドシューター**: 連射が利く万能タイプ
- **ペイントローラー**: 走るだけで道を塗る。近接一撃
- **レーザーチャージャー**: 長押しチャージで最長射程

### コツ（本物のジャンルセオリーそのまま）
- 敵インクの上は遅くなり削られる。自インクの道を作って進む
- インクが切れたら Space で自インクに潜って回復
- 塗るほどスペシャルが溜まる。ゲージが光ったら E

## 開発

- テスト: `node --test tests/unit/core.test.mjs tests/unit/static.test.mjs tests/e2e/e2e.test.mjs`（Node 18+・依存ゼロ）
- 開発実行: `dev3d.html`（3D版）/ `dev.html`（2D版）をローカルサーバー経由で開く
- ビルド: `node scripts/build.mjs` → `index.html`（3D・Three.js同梱）と `classic.html`（2D）を生成
- 設計の要: ゲームロジックは2Dのまま `src/core/`（テスト32件）、3Dは描画層のみ（ADR-006）
- 仕様: `docs/SRS.md` + `docs/SRS_v2_delta.md` / 設計: `docs/SDD.md` / 制約: `CONSTRAINTS.md`

## 再現範囲について（RISK-003）

本作はナワバリバトル型の「塗り合いの遊び」（塗り面積判定・武器役割・インク管理・潜行・スペシャル循環）をオリジナルIPで再現したものです。3D描画・オンライン対戦・任天堂の名称/キャラ/音源は含みません（意図的なスコープ外）。
