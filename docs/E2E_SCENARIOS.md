# E2E_SCENARIOS — INK CLASH（正常3/異常2/境界1）

各シナリオ7項目: ID/目的/前提/手順/期待結果/判定方法/対応要件

## E2E-N1（正常）フルマッチ完走
- 目的: 180秒の試合が完走し勝敗が出る
- 前提: 8体(4v4)・シード固定・全員ボット制御
- 手順: MatchStateを10800tick(180s)実行
- 期待: phase=RESULT、塗り率A+B>40%（ボットPAINT動作の有効性保証=REV-R1-010）、勝者判定がカウントと一致
- 判定: tests/e2e自動 / 要件: FR-MATCH-001, FR-BOT-001

## E2E-N2（正常）塗り返し優勢逆転
- 目的: 終了時点判定の正しさ
- 手順: チームAに90s塗らせる→後半BがAの領域を塗り返す（スクリプト操作）
- 期待: 最終カウントで塗り返し分がBに計上され、Bが勝つ
- 判定: 自動 / FR-MATCH-002

## E2E-N3（正常）スペシャルサイクル
- 目的: 塗り→SP蓄積→発動→インク回復の循環
- 手順: 1体に塗り続けさせSP150到達→発動
- 期待: 発動後 ink=100, sp=0, 前方範囲が自チーム色
- 判定: 自動 / FR-SP-001, FR-INK-001

## E2E-A1（異常）インク枯渇下の連射入力
- 目的: インク0で射撃入力を出し続けても壊れない
- 手順: ink=0で100tick射撃入力
- 期待: 弾は生成されず例外なし、自然回復で再射撃可能になる
- 判定: 自動 / FR-INK-001

## E2E-A2（異常）スプラット中の全入力無効
- 目的: 死亡中に移動/射撃/SPが効かない
- 手順: スプラット直後に全入力を注入
- 期待: 位置・弾・SPが不変、3s後に復活して入力が効く
- 判定: 自動 / FR-DMG-001

## E2E-B1（境界）グリッド端・障害物・time=0同時
- 目的: マップ端(セル0,0/159,89)と障害物への着弾、残0.01sの弾
- 手順: 端と障害物へ着弾、time=0直前に発射
- 期待: 範囲外アクセスなし・障害物塗りなし・終了後は弾が無効
- 判定: 自動 / FR-MATCH-003, FR-PAINT-001
